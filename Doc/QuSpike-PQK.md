# QuSpike-PQK：投影量子核用於譜系分類的提案

> 狀態：**已實作**（2026-11-15）。程式在 `Research/QuSpike_PQK/`，規格與計畫在 `specs/007-pqk-pennylane-ibm/`。
> 以 PennyLane `default.qubit` 實作，硬體路徑就緒但**本階段不送機**（使用者決定）。
> **完整方法論（實作層級、可重現）見 [QuSpike-PQK-方法論.md](QuSpike-PQK-方法論.md)。**
> 取代已停止的 QuSpike-JEPA 路線，結果與停止理由見 [QuSpike-JEPA-研究報告.md](QuSpike-JEPA-研究報告.md)。
> 任務不變：Spike 胺基酸序列 → 22 類 Pango 譜系，`dataset_v2.tsv`，譜系內時間切分，主指標 macro F1。

## 0. 核心轉向

量子部分不再是需要訓練的投影頭，改用**投影量子核（PQK）**——不訓練線路參數，只當固定特徵圖——並且**每個量子元件都配一個等價的古典替身**來檢驗它是否真的有貢獻。

量子只用在古典分不開的子問題上，不在全 22 類上平均稀釋。

## 1. 為什麼換

| 事實 | 來源 | 設計影響 |
|---|---|---|
| 我們的 re-uploading 線路（固定 a=1）輸出度數 ≤ L 的三角多項式；糾纏與可訓練觀測量沒有可檢出貢獻 | v1 §6.3；Schreiber et al. 2022 證明這類模型有古典替身 | **不再用 re-uploading VQC 當主角** |
| 既有量子核在大 Hilbert 空間下核值集中而退化；投影回約化密度矩陣可緩解 | Huang et al. 2021 | 用 **1-RDM 建核**，不用 fidelity kernel |
| 監督線性在突變指標上已達 0.747，所有 JEPA／量子設定都在其下 | v3 §5.1 | 保留跳接作為**結構下限** |
| 損失集中在兩個小群，其餘 11 類已達 0.918 | v3 §5.5 | 量子只用在難群 |
| 訓練式量子模型有優化困難與 GPU 非決定性（同種子差 0.06） | v1 R7 | 不訓練線路 → **結果可重現** |

## 2. 架構

```
序列 ─→ 特徵 F ─┬─→ 跳接 W_s·F ──────────────────────────────────────┐
                │                                                   ├─→ logits
                └─→ 古典路由 r(F) → 難群 g → LDA 降維 z_g → PQK 專家 κ_g ─┘
                                      （易分的那一群不進量子）
```

### 2.1 特徵來源 F

兩個候選：

- `x_mut ∈ {0,1}^V`：對齊後的 0/1 突變指標（V = 3,686；現有參考線 0.747）。
- `e_ESM ∈ ℝ^640`：凍結 ESM-2 t30 150M 平均池化（22 類結果待出；11 類為 0.808，低於突變指標的 0.843）。

**事前規則**：22 類 ESM-2 若比 0.747 高出超過 0.02 則用 ESM-2，否則用 `x_mut`；兩者差距落在雜訊內時用 `x_mut`（較便宜、可解釋）。

**無論選哪個，後續所有對照組都用同一個 F。** 這是為了讓比較只反映特徵圖的差異，不反映特徵來源的差異。

### 2.2 古典路由 r

- 用跳接通道本身（即參考線）預測 22 類，再把預測映射到群：兩個難群 + 一個易分群。
- 易分群直接輸出參考線結果，**不進量子**。
- 路由錯誤由跳接 logits 兜底。
- **單獨報告路由準確率**：它是量子專家能改善的上限。若路由準確率低，專家看到的樣本本身就錯，改善會被抵消。

### 2.3 群內降維 z_g

- 在**訓練集**該群的樣本上擬合 LDA（只用 train，避免洩漏），取 `d_g = min(類別數 − 1, 2n)` 維。
- **用 LDA 而非 PCA**：PCA 保留變異最大的方向，在這裡多半是跨群差異；LDA 直接取群內判別方向，量子特徵圖只需在低維判別子空間上工作。
- 逐維以 train 的 1%／99% 分位數截斷後線性映射到 `[−π/2, π/2]`，沿用 JEPA 設計中避免週期首尾重疊的理由（`R_y(π)` 與 `R_y(−π)` 只差全域相位）。
- **消融**：PCA 版本、以及不降維直接取前 2n 個方向。

### 2.4 PQK 專家 κ_g

依 Huang et al.（2021）的投影量子核，細節以原文為準：

1. **編碼（Hamiltonian evolution，有糾纏）**：n 個 qubit，T 步 Trotter 化演化

   ```
   U(z) = Π_{t=1..T} exp(−i (τ/T) H(z))
   H(z) = Σ_j z_j Z_j  +  Σ_j z_{n+j} (X_j X_{j+1} + Y_j Y_{j+1} + Z_j Z_{j+1})   （環狀）
   ```

   單 qubit 場與鄰接耦合各吃一組特徵，故 n 個 qubit 可吃 2n 維。

2. **投影**：對每個 qubit 取 1-RDM 的 Pauli 期望值

   ```
   φ(z) = (⟨X_k⟩, ⟨Y_k⟩, ⟨Z_k⟩)_{k=1..n} ∈ [−1,1]^{3n}
   ```

3. **核**：`κ(z, z′) = exp(−γ ‖φ(z) − φ(z′)‖²)`

4. **分類器**：群內多類核 SVM（或 Nyström 近似 + 線性層），與跳接 logits 相加。

**不訓練任何線路參數。** 超參數只有 `n, T, τ, γ`，以 validation 網格搜尋。

預設：難群 A 取 n=4、難群 B 取 n=2（依各群類別數決定 LDA 維度，不足 2n 時補零）。另設**放大組** n=8／T=10 檢查規模效應。

### 2.5 為何預期它比 v3 的量子頭更有機會

- 有糾纏的 Hamiltonian evolution 產生的 1-RDM，是 v3 乘積態線路做不到的特徵。**這是唯一讓「量子性」在設計上有機會起作用的地方。**
- 不訓練 → 沒有 barren plateau、沒有種子之間的優化差異。
- 只在小類別數的群內使用，與量子核在小問題上較有競爭力的文獻觀察一致。

## 3. 對照組

全部必跑，且與 PQK 共用 F、路由、LDA、群切分與分類器。

| 代號 | 內容 | 回答的問題 |
|---|---|---|
| **C0** | 只有跳接（參考線） | 結構下限，0.747 |
| **C1** | 群內**古典 RBF 核**，直接作用在 z_g | 「量子特徵圖」相對「不加特徵圖」的增量 |
| **C2** | **RFF 古典替身**：頻率取自 H(z) 的可達頻譜，特徵數 = 3n | 對應 Schreiber／Sweke 的古典替身。**若 PQK ≈ C2，量子部分可被古典取代** |
| **C3** | **無糾纏 PQK**：拿掉 H 中的耦合項，只留單 qubit 場 | 乘積態下 1-RDM 是 z 的 sin／cos，完全古典。**這是量子性的關鍵消融，v1／v3 一直缺的那一個** |
| **C4** | 群內寬度匹配 MLP（隱藏層 = 3n） | 與 v3 寬度匹配對照同精神 |
| **C5** | 不分群、全 22 類的 PQK | 「只用在難群」這個設計本身是否有幫助 |

## 4. 事前判準

雜訊下限沿用 v3 的 **0.02**（§7-R7 的 GPU 非決定性下限），3 種子，差異須**同時**超過 0.02 與兩組的種子標準差。

| 宣稱 | 必要條件 |
|---|---|
| 框架有用 | 完整框架 − C0 > 0.02 |
| 量子特徵有用 | PQK − max(C1, C2, C4) > 0.02 |
| **量子性有用（糾纏有作用）** | PQK − C3 > 0.02 |
| 分群設計有用 | PQK（分群）− C5 > 0.02 |

**停止條件**：P2 完成後，若「量子特徵有用」與「量子性有用」兩項都不成立，結論為「PQK 在本任務上可被古典替代」，**不再加大 n 或調參**，直接寫入報告。

## 5. 報告的量

- 22 類 macro F1、accuracy、F1-weighted、ROC-AUC，3 種子均值 ± 樣本標準差。
- **分群 macro F1**：量子只應改變難群；若易分群也變了，代表路由或兜底有問題。
- 路由準確率、各難群內的混淆矩陣。
- 三個錨點並列：精確簽章查表 0.411、監督線性 0.747、簽章 oracle 0.890–0.930（鬆上界，含大量記憶成分，見報告 §7.2）。
- 成本：模擬秒數、qubit 數、Trotter 步數；以及真機上每樣本所需的線路執行次數（3n 個期望值 × shots）。
- **核值分佈**（off-diagonal 的平均與變異）：檢查 Huang 指出的核集中問題是否出現。

### 實作中發現的三項偏離（詳見 specs/007-pqk-pennylane-ibm/tasks.md）

1. **`qml.TrotterProduct` 不可用作驗證基準**：它在 0.45.1 收斂到 `exp(+iτH)`（與 `qml.evolve` 的 `exp(−iτH)` 相反），且以 Hamiltonian 項的反序施加。改以**精確演化**為 ground truth，實測 O(1/T) 收斂（T=256 時誤差 3.6e-3）。另加測試記錄此慣例。
2. **專家混合權重必須在 validation 上搜尋**：專家輸出與參考線 logits 尺度不同，固定為 1.0 會讓「框架有用」被壞權重拖累。補上後此判準由 −0.016 轉為 +0.031（debug 子集）。所有設定共用同一網格與切分，故設定間的比較不受偏惠。
3. **LDA 維度須用實際出現的類別數**：小樣本下群內可能缺類別，用宣告的 `class_ids` 會超出 sklearn 上界；只剩一類時退回 PCA。對應「群內樣本過少」的 edge case。

**先寫的測試**：

- `entangle=False` 時 1-RDM 等於解析的 sin／cos 形式——**驗證 C3 確實是古典的**；
- τ 固定時 Trotter 誤差隨 T 單調下降；
- 易分群的預測與 C0 **完全相同**（量子不得影響非目標群）；
- LDA 只看 train（給 test 換標籤後 z_g 不變）；
- 核矩陣對稱、半正定、對角為 1。

**成本估計**：n=4 時每個樣本 16 維狀態向量，PQK 特徵抽取在 GPU 上為秒級；最大難群的核矩陣約 360 MB，可直接算。放大組 n=8 仍在 1 分鐘內。整個框架（含所有對照、3 種子）預計 **< 1 小時**，遠低於 v3 單一量子設定的 290 秒 × 種子 × 設定數。

## 8. 預期與風險

**誠實的預期：持平，不是勝出。** PQK 的分離目前只在人造資料上證明過；真實分類資料上，Bowles et al.（2024）比較 12 個量子模型的整體結論是古典模型更好，且移除糾纏常常沒有影響。本框架的價值在於讓「持平」或「勝出」都能被**乾淨地判定**——尤其 C3 是 v1／v3 一直缺的那個對照。

- **R1 上界有限**：損失集中的兩群在 Spike 上的判別訊號本來就少。即使量子專家完美，也受群內資訊限制；這是資料問題，框架無法解決。報告 §7.2 的三個錨點必須一併給出。
- **R2 路由瓶頸**：路由準確率決定量子專家的改善上限，P1 會先量出來。
- **R3 小 n 可被古典精確模擬**：n ≤ 8 時一切都能在古典電腦上算出，這本來就是本提案的前提。問題不是「能否模擬」，而是「這個特徵圖是否比 C1／C2 更適合此資料」。**不得把「古典可模擬」寫成缺陷，也不得把「不可模擬」當成目標。**
- **R4 定位**：本提案不主張量子優勢、量子加速。合理定位是「在一個有強古典基準與可量化上界的真實分類任務上，對投影量子核做有效對照的研究」。

## 9. 結果（2026-11-15，單種子）

資料：`dataset_v2.tsv`，22 類，train 22,175 / test 9,514。特徵：二元突變指標（3,686 維）。
量子位元數：delta 群 n=4、b1 群 n=2；T=4、τ=0.8。完整報告見 `Results/quspike_pqk/report.md`。

### 主結果（test macro F1）

| 設定 | macro F1 | 混合權重 | 秒 |
|---|---|---|---|
| **C2 古典 RFF 替身** | **0.7552** | 0.25 | 576 |
| MAIN 完整框架（PQK + 分群） | 0.7547 | 0.25 | 185 |
| C3 無糾纏 PQK | 0.7544 | 0.5 | 138 |
| C1 群內古典 RBF 核 | 0.7534 | 0.5 | 456 |
| C4 群內寬度匹配 MLP | 0.7489 | 0.25 | 35 |
| C0 僅參考線（結構下限） | 0.7481 | 0 | 1 |
| C5 不分群 PQK | 0.7481 | 0 | 455 |

### 四項判準（全部在雜訊內）

| 宣稱 | A − B | 判定 |
|---|---|---|
| 框架有用（MAIN − C0） | +0.0066 | 在雜訊內 |
| 量子特徵有用（MAIN − C2） | **−0.0005** | 在雜訊內 |
| 量子性有用（MAIN − C3） | **+0.0003** | 在雜訊內 |
| 分群設計有用（MAIN − C5） | +0.0066 | 在雜訊內 |

**§4 的停止條件已觸發**：「量子特徵有用」與「量子性有用」皆不成立，不得以加大 n、改 τ／T／gamma 的方式重試求轉正。

### 三個關鍵觀察

**(a) 糾纏的貢獻是 +0.0003。** C3 把 Hamiltonian 的耦合項整個移除後分數幾乎不變。而 C3 在數學上就是 `z` 的 cos／sin（以閉式解驗證，誤差 2.2×10⁻¹⁵），完全古典。因此這個線路的「量子性」在本任務上**沒有可檢出的貢獻**——這正是 v1／v3 一直缺的對照，現在有了乾淨的答案。

**(b) 古典 RFF 替身是全場最高分。** 依 Schreiber et al.（arXiv:2206.11740），這類演化型量子模型存在古典替身；實測確認替身不只持平，還略勝一籌（+0.0005，同樣在雜訊內）。

**(c) 成本結構與直覺相反。** 量子特徵只花 **0.37 秒**（n≤4、批次廣播），而古典 SVM 花 456–576 秒。瓶頸 100% 在古典分類器，不在量子模擬。

### 分群分解（量子只動到難群）

| 設定 | b1 | delta | others |
|---|---|---|---|
| C0 僅參考線 | 0.550 | 0.601 | 0.949 |
| MAIN 完整框架 | 0.567 | 0.612 | 0.949 |
| C3 無糾纏 | 0.563 | 0.613 | 0.949 |

`others` 在所有設定完全相同（0.949），且**易分群預測與 C0 的差異筆數為 0**（SC-004 通過）。路由準確率 0.967，所以結論不是被路由瓶頸造成的。

### 限制（必須與結果並列）

1. **只跑 1 顆種子，未滿足 FR-012 的「≥3 種子」。** 單種子標準差為 0，判定退化成只與 0.02 雜訊下限比較。結論方向很可能穩健（最大增量 +0.0066，離門檻差三倍），但這是**指示性結果**，不是已滿足判準的結果。
2. **計畫的成本估算錯誤。** SC-005 訂一小時內完成七組 × 3 種子；實測單種子七組已 31 分鐘。Phase 0 只量了量子特徵，漏算 9,538 樣本的 precomputed-kernel SVM。
3. **硬體路徑未實際驗證。** 本階段不送機（§2 前提）；憑證驗證與裝置列舉需網路，首次執行前屬未驗證。
4. 上界 0.930 為**樂觀估計**，不是可達成目標（研究報告 §7.2）。

MAIN 在有限取樣下退化到與 C0 完全相同，是因為 validation 選到混合權重 0（即「不要專家」）——取樣噪聲讓專家變得無用，這本身就是有資訊的觀察。

**一項建構上的發現：去極化噪聲對本管線完全沒有影響。** 單位元去極化把每一個 Pauli 期望值乘上同一個常數（p=0.02 時為 1−4p/3 = 0.97333，逐樣本差異在機器精度 4×10⁻¹⁶ 內），而 RBF 核的中位數啟發式 gamma 正比於 1/median(d²)，剛好把這個均勻縮放完全吸收——實測核矩陣**逐位元相同**（最大差 0.000×10⁰，p 至 0.1 皆然）。

這對 PQK 是真實的優點（對全域去極化精確不變），但也意味著**掃描中的 `noise_p` 軸在建構上無資訊**，唯一有資訊的噪聲軸是有限取樣。若要測量去極化的影響，必須改用固定的 gamma（放棄中位數啟發式），或改用對尺度敏感的核。此點原設計未預見。
