## 1. 設計原則

四條原則決定了整個架構的形狀。它們不是風格偏好，每一條都來自前兩輪的一次具體失敗。

| # | 原則 | 實作方式 | 來自哪個教訓 |
|---|---|---|---|
| P1 | **量子部分不訓練任何參數** | 固定特徵圖，可調的只有 `n, T, τ, γ` | v3 的可訓練量子頭無法排除「優化困難」這個解釋 |
| P2 | **強基準線必須是結構下限** | `logits = ref_logits + s·expert_block`，`s=0` 即還原基準線 | v1／v3 都追不上基準線，但無法證明不是優化問題 |
| P3 | **每個量子元件都要有等價的古典替身** | C1／C2／C3／C4 四個對照 | v1 的「量子優勢」是對照組缺陷造成的假象 |
| P4 | **判準與停止條件事前訂定** | `criteria.py` 硬編碼四項宣稱與 0.02 下限 | 避免事後挑選結論 |

P1 的推論很重要：**φ 只依賴輸入與超參數，與隨機種子無關**，因此可跨種子、跨設定快取重用（§5.4）。

## 2. 資料與特徵

### 2.1 資料

`Data/spike-lineage/dataset_v2.tsv`：22 個 Pango 譜系，31,689 條序列。

| 項目 | 值 |
|---|---|
| train／test | 22,175 ／ 9,514 |
| 切分方式 | **每譜系內按採集日期排序，前 70% 為 train、後 30% 為 test**（時間切分，非隨機） |
| validation | train 內每類別日期最晚的 15%（`features.split_validation`） |
| 每譜系上限 | 3,000（固定種子抽樣） |

時間切分意味著測試集含訓練期未見過的突變組合——這是刻意的，用來避免記憶式的高分。

### 2.2 輸入特徵 F

對齊 Wuhan-Hu-1 後的**二元突變指標**：

```
x_mut ∈ {0,1}^V,  V = 3,686
```

每一維對應一個 (位置, 胺基酸) token；`X`（定序缺失）排除在外。詞彙表只從 train 建立。

**為何不用蛋白質語言模型嵌入**：事前規則是「22 類凍結 ESM-2 若超過參考線 0.747 達 0.02 以上就改用它」。實測 ESM-2 t30 150M 平均池化得 **0.6786**（3 種子，標準差 0），低於參考線 0.068，故採用突變指標。詳見 `specs/007-pqk-pennylane-ibm/research.md` D8。

### 2.3 分群

損失集中在兩群，量子只用在這兩群上，不在全 22 類上平均稀釋：

| 群 | 類別 | train | test | 進量子 |
|---|---|---|---|---|
| `delta` | B.1.617.2 + AY.103／AY.2／AY.25／AY.3／AY.4／AY.44 | 9,538 | 4,091 | ✅ |
| `b1` | B.1／B.1.1／B.1.2／B.1.177 | 4,200 | 1,801 | ✅ |
| `others` | 其餘 11 類 | 8,437 | 3,622 | ❌ |

群內類別數 < 2 或 train 樣本 < 50 時自動降級為不走量子（`features.degrade_if_too_small`）。

## 3. 古典路由

路由器**就是監督線性參考線本身**，這讓它同時扮演三個角色：對照組 C0、架構下限、以及分群的依據。

```
ref_logits = W·x_mut + b          # 線性層，22 類輸出
```

訓練：AdamW，lr 3e-3，weight decay 1e-4，batch 512，60 epochs（與 `QuSpike_JEPA.baselines.mutset_linear` 同設定，確保與前兩輪可比）。

路由規則：`argmax(ref_logits)` 的類別屬於哪一群，樣本就路由到哪一群。`others` 群直接輸出參考線的預測，不經任何量子路徑。

**路由準確率**（樣本被分到其真實類別所屬群的比例）= **0.9667**。這是量子專家能改善的上限——被路錯群的樣本，專家根本看不到。報告必須單獨列出此數字，否則無法判斷結論是不是被路由瓶頸造成的。

## 4. 群內降維

量子線路只能吃 `2n` 維（n 個單位元場 + n 個耦合強度），而特徵是 3,686 維，所以必須降維。

```
LDA（只用 train 擬合）→ 分位數截斷 → 線性映射到 [−π/2, π/2] → 補零至 2n 維
```

| 群 | n | 2n | LDA 維度 k | 補零 |
|---|---|---|---|---|
| `delta` | 4 | 8 | 6（= 類別數 − 1） | 2 |
| `b1` | 2 | 4 | 3（= 類別數 − 1） | 1 |

三個實作細節，每一個都有理由：

1. **用 LDA 而非 PCA**：PCA 保留變異最大的方向，但我們已經分好群，群內最大的變異多半不是判別方向。LDA 直接取群內判別方向，讓量子特徵圖在低維判別子空間上工作。
2. **只用 train 擬合**（FR-003）：有測試保證——把 test 標籤打亂後 `z_test` 必須逐元素不變。
3. **縮放到 `[−π/2, π/2]`**：用 train 的 1%／99% 分位數截斷後線性映射。不用 min-max 是避免極端值壓縮動態範圍；不用 `[−π, π]` 是因為 `R_y(π)` 與 `R_y(−π)` 只差全域相位，編碼器飽和時兩個極端會被映到同一點。

維度不足 `2n` 時補零，且補零維度在 `z` 中恆為 0（有測試保證）。

**邊界情況**：小樣本下群內可能缺類別，故 `n_components` 以**實際出現**的類別數計算；只剩一類時退回 PCA。

## 5. 量子特徵圖（核心）

### 5.1 線路

n 個量子位元，初態 `|+⟩^n`（一層 Hadamard），對 Hamiltonian 做一階 Trotter 演化：

```
H(z) = Σ_j z_j Z_j  +  Σ_{(j,k)∈ring} z_{n+j} (X_j X_k + Y_j Y_k + Z_j Z_k)

U(z) = [ Π_j exp(−i·dt·z_j·Z_j) · Π_{(j,k)} exp(−i·dt·z_{n+j}·(XX+YY+ZZ)) ]^T,   dt = τ/T
```

前 n 維特徵進單位元場，後 n 維進鄰接耦合（環狀；n=2 時環上只有一條邊，不重複施加）。

**預設**：`T = 4`、`τ = 0.8`。

### 5.2 閘分解（不用 `qml.TrotterProduct`）

每個 Trotter 步展開成顯式閘：

```python
for _ in range(T):
    for j in range(n):
        RZ(2·dt·z[j], wires=j)
    for (j, k) in ring:
        IsingXX(2·dt·z[n+j], wires=[j,k])
        IsingYY(2·dt·z[n+j], wires=[j,k])
        IsingZZ(2·dt·z[n+j], wires=[j,k])
```

**為何不用 `qml.TrotterProduct`**：它搭配資料相依的 Hamiltonian 係數**無法參數廣播**（批次輸入會丟 `RuntimeError`），逐樣本呼叫慢兩個數量級。顯式分解讓閘角度成為可廣播參數。

**兩個必須知道的上游行為**（實測，PennyLane 0.45.1）：

- `qml.TrotterProduct(H, time=τ)` 收斂到 **`exp(+iτH)`**，與 `qml.evolve` 的 `exp(−iτH)` **相反**。要與本實作一致須傳 `time=−τ`。
- 它以 Hamiltonian 項的**反序**施加；一階 Trotter 對順序敏感，兩者皆為合法近似但不是同一個算符。

因此正確性驗證**不以 `TrotterProduct` 為基準**，改用精確演化 `exp(−iτH)`：

| T | 4 | 16 | 64 | 256 |
|---|---|---|---|---|
| 最大誤差（n=3, τ=0.7） | 2.27e-1 | 5.78e-2 | 1.45e-2 | 3.63e-3 |

誤差約 O(1/T)，符合一階 Trotter 理論。

### 5.3 投影讀出

對每個量子位元取 1-RDM 的 Pauli 期望值：

```
φ(z) = (⟨X_k⟩, ⟨Y_k⟩, ⟨Z_k⟩)_{k=1..n} ∈ [−1,1]^{3n}
```

**為何投影而非 fidelity kernel**：Huang et al.（2021）指出既有量子核在大 Hilbert 空間下會出現核值集中而退化；投影回約化密度矩陣可緩解。實作中另有核值分佈診斷（§6.3）來監測這個現象是否仍發生。

### 5.4 執行與快取

PennyLane `default.qubit`，torch interface，`diff_method=None`（不需梯度），批次大小 4096。

**選 `default.qubit` 而非 `lightning.qubit`**：實測 n=4、T=4、512 筆，`default.qubit` 0.671 ms/樣本，`lightning.qubit` 9.906 ms/樣本——**慢 15 倍**，因為它對批次維度逐筆迴圈，C++ 的單樣本優勢被抵銷。

**快取鍵**（`pqk.cache_key`）：

```
sha256(data_hash, group, projection, n_qubits, T, τ, entangle, shots, noise_p, backend)[:16]
```

**刻意不含種子**——這是 P1 的直接推論。實測效果：首次 0.37 s → 命中後 **0.005 s**（74 倍）。形狀不符時視為失效並重算，不靜默使用舊資料。

## 6. 核與群內專家

### 6.1 RBF 核

```
κ(φ_i, φ_j) = exp(−γ‖φ_i − φ_j‖²),   γ = 1 / (2·median‖φ_a − φ_b‖²)
```

γ 用中位數啟發式（在 512 筆子樣本上估計），核矩陣以 float32 儲存。

**一個重要的副作用**：中位數啟發式使核**對特徵的均勻縮放完全不變**。單位元去極化噪聲正好是均勻縮放（p 時每個期望值乘 1−4p/3，實測逐樣本差異 4×10⁻¹⁶），因此**去極化噪聲對本管線的核矩陣逐位元無影響**。這對 PQK 是真實的穩健性優點，但也代表噪聲掃描的 `noise_p` 軸無法測出任何東西（§8）。要測量去極化影響必須改用固定 γ。

### 6.2 半正定修正

核矩陣必須對稱、對角為 1、半正定。偵測到最小特徵值 < −1e-8 時：特徵值截斷至 0 → 重新正規化對角回到 1，並記錄修正方式。**不得靜默通過**。

### 6.3 診斷

記錄 off-diagonal 的平均與標準差。變異極小代表核值集中（Huang 指出的退化模式）。

### 6.4 專家

群內多類 SVM，`kernel='precomputed'`，`C=10`，one-vs-rest。

記憶體預算 2 GB：`n²×8 > 2e9` 時改用 Nyström 近似（m=2048）並記錄 `approximation` 與近似造成的分數差。實測 `delta` 群精確核為 364 MB（float32），不需近似。

專家的 `decision_function` 輸出攤回 22 類的 logits 區塊，只填該群的類別欄位，其餘為 0。

## 7. 合併與混合權重

```
logits = ref_logits + Σ_g  1[routed == g] · s · block_g
pred   = argmax(softmax(logits))
```

`s = 0` 時整個模型還原成參考線——這就是 P2 的結構下限。

### 7.1 混合權重必須在 validation 上選

專家輸出（SVM decision_function）與參考線 logits 的**尺度不同**，固定 `s = 1.0` 等於隨機挑一個混合權重。

這不是細節：實測在 debug 子集上，固定 `s=1.0` 時「框架有用」為 **−0.016**，在 validation 上調過後為 **+0.031**。一個沒調過的權重就足以造出假的負面結果。

**選法**：網格 `s ∈ {0, 0.25, 0.5, 1, 2, 4}`，在 validation（train 內每類別最晚 15%）上選 macro F1 最高者。

**公平性保證**：所有設定（MAIN 與全部對照組）共用**同一個網格、同一個 validation 切分、同一個選擇規則**，因此設定之間的比較不受此步驟偏惠。

**效率**：專家的擬合與 `s` 無關（只有輸出縮放有關），故只擬合一次再逐一套用網格。

完整框架選到的權重是 **s = 0.25**。

## 8. 對照組與判準

### 8.1 七組設定

全部共用同一個 FeatureSet、路由、降維方式、分類器型別與權重網格，**只在特徵圖處不同**。

| 代號 | 特徵圖 | 糾纏 | 分群 | 回答什麼 |
|---|---|---|---|---|
| `MAIN` | PQK | ✅ | ✅ | — |
| `C0` | 無（僅參考線） | — | — | 框架有用？ |
| `C1` | 群內古典 RBF（直接作用在 z） | — | ✅ | 量子特徵 vs 不加特徵圖 |
| `C2` | **古典 RFF 替身** | — | ✅ | 量子可否被古典取代 |
| `C3` | **PQK 但關掉耦合項** | ❌ | ✅ | **量子性有用？** |
| `C4` | 寬度匹配 MLP（隱藏層 = 3n） | — | ✅ | 等容量古典網路 |
| `C5` | PQK，不分群（全 22 類一個專家） | ✅ | ❌ | 分群設計有用？ |

**C3 是整個框架最關鍵的對照。** 關掉耦合項後，乘積態的 1-RDM 有閉式解：

```
⟨X_j⟩ = cos(2τ z_j),   ⟨Y_j⟩ = sin(2τ z_j),   ⟨Z_j⟩ = 0
```

實測與閉式解的最大誤差 **2.22×10⁻¹⁵**，所以 C3 **在數學上就是純古典的 cos／sin**。`MAIN − C3` 因此是唯一能支持「糾纏有作用」的證據。這是 v1／v3 一直缺的那個對照。

**C2（RFF 替身）**依 Schreiber et al.（arXiv:2206.11740）：大類演化型量子模型存在古典替身。頻率取自 Trotter 演化可達的尺度（σ = 2τ），cos／sin 基底（與量子期望值同樣有界），特徵數對齊 `3n`。

### 8.2 判準

雜訊下限 **0.02**（約為同種子 GPU 重跑差異的下限，見研究報告 §7-R7）。

| 宣稱 | A | B | 成立條件 |
|---|---|---|---|
| 框架有用 | MAIN | C0 | > 0.02 |
| 量子特徵有用 | MAIN | **max(C1, C2, C4)** | > 0.02 |
| 量子性有用 | MAIN | C3 | > 0.02 |
| 分群設計有用 | MAIN | C5 | > 0.02 |

`holds` 須**同時**滿足 `Δ > 0.02` 與 `Δ > max(std_A, std_B)`；`|Δ| ≤ max(0.02, std)` → `within_noise`；否則 `fails`。三態全部由程式判定，不留需人工解讀的欄位。

「量子特徵有用」刻意對上**最強**的古典對照（三者中平均最高者），否則挑弱的比會高估量子的增量。

### 8.3 停止條件（事前訂定）

若「量子特徵有用」與「量子性有用」**兩項都不成立**，結論為「PQK 在本任務上可被古典替代」，**不得**以加大 n、改 τ／T／γ 的方式重試求轉正。

此約束的存在是為了避免重演前一輪的調參循環。

## 9. 結果與限制

### 9.1 主結果（單種子）

| 設定 | macro F1 | 混合權重 | 秒 |
|---|---|---|---|
| C2 古典 RFF 替身 | **0.7552** | 0.25 | 576 |
| **MAIN 完整框架** | **0.7547** | 0.25 | 185 |
| C3 無糾纏 PQK | 0.7544 | 0.5 | 138 |
| C1 群內古典 RBF | 0.7534 | 0.5 | 456 |
| C4 寬度匹配 MLP | 0.7489 | 0.25 | 35 |
| C0 僅參考線 | 0.7481 | 0 | 1 |
| C5 不分群 PQK | 0.7481 | 0 | 455 |

四項判準**全部在雜訊內**：框架 +0.0066、量子特徵 −0.0005、**量子性 +0.0003**、分群 +0.0066。停止條件觸發。

### 9.2 分群分解

| 設定 | b1 | delta | others |
|---|---|---|---|
| C0 僅參考線 | 0.550 | 0.601 | 0.949 |
| MAIN | 0.567 | 0.612 | 0.949 |
| C3 無糾纏 | 0.563 | 0.613 | 0.949 |

`others` 在所有設定完全相同，且**易分群的預測與 C0 逐筆相同（差異 0 筆）**——這驗證了量子路徑確實只動到目標群。

### 9.3 成本結構（與直覺相反）

| 階段 | 時間 |
|---|---|
| 量子特徵（n≤4，19,630 筆） | **0.37 s** |
| 古典 SVM（delta 群 9,538 樣本） | 185–576 s |

**瓶頸 100% 在古典分類器，不在量子模擬。** 這也意味著原計畫的成本估算錯了——Phase 0 只量了量子部分。

### 9.4 必須與結果並列的限制

1. **只跑 1 顆種子**，未滿足「≥3 種子」的要求。標準差為 0，判定退化成只與 0.02 下限比較。結論方向很可能穩健（最大增量 +0.0066，離門檻差三倍），但這是**指示性結果**。
2. **噪聲掃描的去極化軸無資訊**（§6.1）。唯一有資訊的是有限取樣：最低取樣次數 1024，掉點全部 ≤ 0.007。
3. **硬體路徑未實際驗證**：本階段不送機。估算顯示單是 delta 群測試集就需約 3.5 小時裝置時間、164 個作業，而免費方案是每月數分鐘級。
4. 標籤歧義上界 0.930 是**樂觀估計**（57.3% 的測試序列有獨一無二的突變簽章，等於被背下來），不是可達成目標。

## 10. 可重現性

```bash
conda activate qml_env

# 主管線（七組設定）
python -m Research.QuSpike_PQK.run --seeds 0 --out Results/quspike_pqk

# 噪聲掃描
python -m Research.QuSpike_PQK.run noise --shots-list null,8192,1024,256 \
  --noise-list 0,0.02 --subset 1500 --out Results/quspike_pqk

# 硬體乾跑（預設完全離線、不送機）
python -m Research.QuSpike_PQK.run hardware --samples 500 --budget-seconds 600

# 報告
python -m Research.QuSpike_PQK.report --out Results/quspike_pqk --write Results/quspike_pqk/report.md
```

每個結果 JSON 含完整 `config`、`split_version`（資料雜湊 + 切分規則版本）與 `environment`，足以重建執行。

**驗證過的不變量**：
- 同種子重跑 → 主指標差異 **0.00e+00**
- 易分群預測與 C0 → 差異 **0 筆**
- 無糾纏特徵與閉式解 → 誤差 **2.22e-15**
- 快取命中 → 0.37 s → 0.005 s
- 完整測試套件 **380 項全數通過**，日誌零連線痕跡

**兩道預設關閉的安全閘門**：
- `submit=False`：不送出任何硬體作業
- `allow_network=False`：完全不連線（此閘門是在一次憑證外送事故後補上的，見 `specs/007-pqk-pennylane-ibm/quickstart-validation.md` 的事故紀錄）
