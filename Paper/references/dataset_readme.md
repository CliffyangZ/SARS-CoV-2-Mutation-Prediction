# SARS-CoV-2 Spike 譜系分類資料集

從 NCBI Virus（NCBI Datasets）抓取、去重並切分好的 Spike 胺基酸序列，用於 **Pango 譜系的多類別分類**（對應 arXiv:2501.14746 的 Spike7k 任務）。

目錄內有三份產物：`dataset.tsv`（初版 11 譜系）、`dataset_full.tsv`（擴充後未封頂）、**`dataset_v2.tsv`（擴充後每譜系最多 3000 條，建議用於訓練）**。

## 檔案

| 檔案 | 說明 |
|---|---|
| `raw/<譜系>.zip` | 初版下載，14 個譜系（約 26 MB） |
| `raw_ext/<譜系>.zip` | 擴充下載，另 9 個大型／對照譜系（約 76 MB） |
| `build_dataset.py` | 讀取 zip → 過濾、去重、切分 |
| `dataset.tsv` / `stats.json` | 初版：僅 `raw/`，17,258 條、11 譜系（約 22 MB） |
| `dataset_full.tsv` / `stats_full.json` | `raw/`+`raw_ext/`，未封頂，42,805 條、22 譜系（約 54 MB） |
| `dataset_v2.tsv` / `stats_v2.json` | 同上來源，但 `--max-per-lineage 3000`，31,689 條、22 譜系（約 40 MB） |

TSV 欄位（三份相同）：

| 欄位 | 說明 |
|---|---|
| `lineage` | Pango 譜系（標籤） |
| `accession` | 該序列第一次出現時的蛋白質 accession |
| `date` | 同一序列的最早採集日期（有些只有年份或年月） |
| `count` | 去重前這條序列出現的次數 |
| `split` | `train` 或 `test` |
| `sequence` | Spike 胺基酸序列 |

## 資料來源

- NCBI Datasets CLI，初版下載約 2026-11-14；`raw_ext/` 為同流程後續擴充。
- 指令範例：

```bash
datasets download virus protein S --lineage P.1 --complete-only --host human --filename P.1.zip
```

- 篩選條件：SARS-CoV-2、蛋白質 S（surface glycoprotein）、`--complete-only`、宿主為人類。
- `--lineage` 是**精確比對**，不含子譜系。
- 序列標頭本身沒有譜系；標籤取自每個 zip 的檔名譜系，並與 `data_report.jsonl` 的 `pangolinClassification` 對應（初版曾抽查 R.1）。
- 採集日期由 `data_report.jsonl` 以 isolate 名稱對應到 FASTA 標頭取得。

## 建置流程（`build_dataset.py`）

1. 讀取每個 zip 的 `protein.faa` 與 `data_report.jsonl`，以 isolate 名稱對應日期。
2. 品質過濾：只允許 20 種標準胺基酸與 `X`；`X` 比例不得超過 5%；長度需在 1200–1300。
3. 以完整序列去重，保留最早日期，並記錄出現次數。
4. 同一序列出現在多個譜系時（標籤衝突）整條刪除。
5. （可選）`--max-per-lineage`：每個譜系固定種子隨機抽樣，上限為指定條數。
6. 唯一序列少於 `--min-unique` 的譜系整個刪除。
7. 每個譜系按採集日期排序，前 70% 為 train，後 30% 為 test。沒有日期的序列歸入 train。

重新建置：

```bash
# 初版（僅 raw/，與 dataset.tsv 相同）
python build_dataset.py

# 擴充全量（raw + raw_ext，未封頂 → dataset_full.tsv）
python build_dataset.py --raw-dirs raw raw_ext --out dataset_full.tsv --stats stats_full.json --min-unique 30

# 建議訓練用（每譜系最多 3000 → dataset_v2.tsv）
python build_dataset.py --raw-dirs raw raw_ext --out dataset_v2.tsv --stats stats_v2.json \
  --min-unique 30 --max-per-lineage 3000 --seed 0
```

## 使用時的注意事項

1. **類別仍不平衡**：`dataset_v2` 最大類（3,000）與最小類（B.1.617.1，45）約差 67 倍；`dataset_full` 更嚴重（B.1.1.7 10,122 vs 45，約 225 倍）。評估請看 **macro F1**，不要只看 accuracy。
2. **序列長度不一致**（以 v2 為例）：1273 aa 約 14,919 條，1271 aa 約 12,578 條，其餘為 1270 等。定長編碼前需統一長度，否則模型可能把長度當成譜系捷徑。
3. **含 `X`**：v2 中約 17,024 / 31,689 條含少量 `X`。需自行決定保留、補回或剔除。
4. **日期精度不一**：部分只有年份或年月，只影響切分邊界附近的排序。
5. **相近譜系難分**：AY 系列（Delta 子譜系）、B.1.427 / B.1.429（Epsilon）、以及 B.1 與其子譜系彼此高度相似。
6. **時間範圍大致到 2022 年**：沒有涵蓋後期 Omicron 細分譜系的完整取樣設計。
7. 去重以「完全相同序列」判定，仍存在大量只差 1–2 個胺基酸的近似序列。
8. 合併 `raw_ext` 後，部分初版譜系的唯一序列數會略降（跨譜系衝突變多），因此 `dataset.tsv` 與 full/v2 中同譜系數量不必逐條相等。

## 與原論文（Spike7k）的差異

| | 原論文 | 本資料集（v2） |
|---|---|---|
| 來源 | GISAID | NCBI（公開，免註冊） |
| 規模 | 7,000 條 | 31,689 條（已去重、封頂） |
| 譜系數 | 22 | 22 |
| 最大類 | B.1.1.7，48% | 封頂後約 9.5% |
| 去重 | 未說明 | 完全相同序列去重 |
| 切分 | 70/30，5 折 | 按時間 70/30（單次） |

譜系組成已較接近論文（含 B.1.1.7、B.1.617.2、B.1.2、B.1、AY.4 等），但取樣與切分仍不同，**結果不宜與論文數字直接比較**。
